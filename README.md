# DET Dictation Trainer

Personal dictation practice page for Duolingo English Test training.

## How to add sentences

Edit `sentences.txt`.

- Put one English sentence on each line.
- Blank lines are ignored.
- Lines starting with `#` are ignored.

## Files

- `index.html`: page structure
- `style.css`: visual design
- `app.js`: practice logic and browser TTS
- `sentences.txt`: sentence list

## GitHub Pages

Upload these files to a public GitHub repository, then enable GitHub Pages from the repository settings.
